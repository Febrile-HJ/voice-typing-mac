# Joseph's Voice-Typing (맥)

단축키 하나로 말하면 글이 되는 받아쓰기 앱입니다. 조셉이 직접 만들어 지인에게 나눠 주는 앱이고, 설치 파일은 비밀번호로 잠겨 있습니다.

## 필요한 것

- Apple 실리콘(M 시리즈) 맥, macOS 14 이상
- 조셉에게 받은 설치 비밀번호

## 설치

1. **터미널**을 엽니다 (⌘ Space → "터미널").
2. 아래 한 줄을 붙여 넣고 Enter 를 누릅니다.

   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Febrile-HJ/voice-typing-mac/main/install.sh)"
   ```

3. 비밀번호 창이 뜨면 조셉에게 받은 비밀번호를 넣습니다.
4. 앱이 켜지면 macOS 가 묻는 두 가지만 허용합니다.
   - 마이크: **허용**
   - 손쉬운 사용: **시스템 설정 열기** → 목록의 **Voice-Typing** 켜기 (켜면 바로 됩니다)
5. 처음 설정 화면에서 음성 인식 모델(약 1.5GB) 받기와 AI 연결을 마칩니다.

## 업데이트

새 판이 나오면 앱이 알려 줍니다. 메뉴 막대의 Voice-Typing › **업데이트**를 누르면 받아서 바꿔 끼우고 다시 켭니다. 설정·기록·인식 모델은 그대로입니다. 키체인 암호를 물으면 맥 로그인 암호를 넣고 **항상 허용**을 누릅니다.

설치 명령을 다시 실행해도 최신 판으로 바뀝니다.

## 알아 둘 것

- 이 앱은 Apple 공증을 받지 않았습니다. 조셉을 믿고 설치하는 앱입니다. 설치 명령은 조셉 인증서로 서명된 앱인지 확인한 뒤에만 넣습니다.
- 옛 판은 휴지통으로 옮겨 둡니다.
- 지우려면: 메뉴 막대 › 종료 → 응용 프로그램의 Voice-Typing 을 휴지통으로. 설정·기록은 `~/.voice-typing` 에 있습니다.
